# i™ THE ONE — Public PWA Preview

This review branch publishes a local-first Buddy and receipt prototype to a separate Render static site. No model inference or distributed SOURCECHAIN backend is connected. Receipts stay in browser localStorage; SHA-256 proves only integrity. No personal information should be entered for sensitive use. Install via iPhone Safari Share → Add to Home Screen. The production igptm.com DNS and central private repository are unchanged.
